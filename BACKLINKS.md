# SEO and backlink playbook

Backlinks are links from **other websites** to yours, so no code can create them for you. What the project does give you is everything that makes earning them easy. Never buy links or use link farms, comment spam or private blog networks: Google treats these as spam and can remove your site from search.

## Already built into the site

| Feature | Why it helps |
|---|---|
| 40 prompt pages + 6 category pages | More indexable pages; each can rank for long-tail searches like "perfume ad AI video prompt" |
| Share buttons (X, Reddit, Pinterest, LinkedIn, Facebook, WhatsApp) on every prompt | Makes it one click for visitors to spread and link your pages |
| `/link-to-us/` page with text links and a badge | Gives bloggers and directories ready-made HTML to link to you |
| RSS feed (`/feed.xml`) | Lets aggregators and readers subscribe; helps discovery |
| `sitemap.xml`, `robots.txt`, canonical URLs, Open Graph, JSON-LD | Helps Google index and display pages correctly |
| `llms.txt` | A summary file for AI assistants and crawlers |
| Site search (header icon or `/`) | Keeps visitors on the site longer and helps them find prompts |
| Internal links between tools, categories, prompts and guides | Spreads authority through the site |

## Where to earn real backlinks (all free)

1. **Google Search Console and Bing Webmaster Tools.** Submit the sitemap first. This is not a backlink but it gets you indexed.
2. **AI tool directories.** Submit each tool page to reputable directories (for example There's An AI For That, Futurepedia, Toolify and similar). Check each site's current submission rules.
3. **Product Hunt, Hacker News (Show HN), Indie Hackers.** One honest launch post with a clear description of what is free.
4. **Reddit and Discord communities** about AI video and prompting. Follow each community's self-promotion rules: share a useful prompt or tip first, link only when relevant.
5. **Pinterest.** Pin prompt pages with a screenshot of the prompt. Pinterest links can drive steady traffic.
6. **YouTube and TikTok.** Make short videos using prompts from the library and put the prompt page in the description.
7. **Guest posts and tutorials** on Medium, Dev.to, Substack or niche blogs, linking to the matching tool or guide.
8. **Resource lists.** Search for "AI video tools list" or "best prompt generators" pages and politely email the owner suggesting your tool, pointing to `/link-to-us/`.
9. **Journalist and expert quote services** (such as Qwoted or Featured) to earn links from articles.
10. **GitHub.** Publish the project as open source with a link in the README, and look for "awesome AI video" lists that accept submissions.

## Habits that grow traffic

- Add 2 to 4 new viral prompts a week in `lib/viral.ts` (the site builds their pages automatically).
- Write one helpful guide a week in `lib/posts.ts`.
- Update the sitemap in Search Console after big batches.
- Check Search Console's Performance report monthly and write more about queries that already get impressions.
